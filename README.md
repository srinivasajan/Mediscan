# Mediscan Zeta

Live: https://mediscan-zeta.vercel.app

Mediscan Zeta is a simple experimental web app where you **click a photo of a medicine** and the system **analyzes the image and tells you information about that medicine**.

Basic idea:
- You upload or click a picture of a medicine
- The app scans the image
- It identifies the medicine (name, type, basic details)
- It shows information related to that medicine

This project is mainly built for:
- Learning
- Experimentation with image recognition
- Playing with medical data extraction
- Prototyping real-world AI use cases

Note:  
This is an experimental tool, not a certified medical system.  
Do not rely on it for medical diagnosis or prescriptions.
